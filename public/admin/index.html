WFHS CS Club Content Studio

Add projects and events without touching source code.

Use this editor to create new project collections, add event entries, upload images, and keep the site current from a friendly form instead of editing MDX.

  • Projects live in content/projects and can be collections or standalone builds.
  • Events live in content/events and can be posted by any club editor.
  • Cover images upload into the repo automatically, so the site updates with the new content.
  • Use the editor for titles, summaries, tags, dates, and nested child project slugs.

How to use it

No coding needed

Sign in with GitHub, pick Projects or Events, then fill out the form. If you are making a collection, add child project slugs like scratch-maze-escape so the site can nest it.
